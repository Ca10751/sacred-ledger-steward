# Sapucaí Tropicalis

Construa um sistema web de gestão e escrituração contábil multi-empresa com suporte a igrejas e empresas comerciais:

- Administradores e seletor de empresas/organizações, onde cada empresa ou igreja mostre exclusivamente suas respectivas informações (multi-tenant isolado).
- Comece pelo seletor de empresas e pelas telas de lançamentos contábeis.
- Lançamentos contábeis com suporte tanto a partidas dobradas (débito e crédito) quanto a partidas simples, vinculados a um plano de contas e centro de custos.
- Estrutura para DRE, balancete de verificação e razonetes (contas T).
- Módulo e controles específicos para igrejas (dízimos, ofertas, congregações, prestação de contas estatutária / superávit ou déficit).
- Não deve conter assistente ou chat de IA na interface: o sistema deve ser simples, direto, de fácil entendimento, rápido, otimizado e confiável.
